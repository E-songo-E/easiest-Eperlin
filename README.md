# easiest e-perlin noise generation

A procedural world generation algorithm made for Voxel games using web technologies.  
Generates hills, valleys, trees, and layered terrain using Perlin noise. Fully open-source and lightweight.

---

## Features

- Procedural terrain using **Perlin noise**
- Layered blocks: **Grass, Dirt, Stone**
- Random **trees** on grass blocks
- Optional **water** in low-lying areas
- Seed-based generation for **repeatable worlds**
- Pure JavaScript, no external dependencies
- Compatible with **custom engines out-of-the-box**

_Tho you may need to adjust it to be compatible with your engine/game_
